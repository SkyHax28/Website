LiquidBounce

LiquidBounce is a free and open-source mixin-based client using the Fabric API or Forge for Minecraft. This mod gives you significant advantages over other players. With its JavaScript API, you can develop your own modules and share them with the community. Customize the HUD to your exact needs with a beautiful shader-based main menu.

Download LiquidBounce

Meteor Client

Meteor Client comes with an extremely customizable GUI and HUD, giving you a beautiful but functional interface to interact with, along with powerful modules for PvP, utility, and movement. It’s a Fabric-based client ideal for anarchy servers, offering features like AutoClicker, XRay, and Fly.

Download Meteor Client

Download RavenXD

Altmanager

Altmanager is a utility-focused client designed to manage multiple Minecraft accounts seamlessly. It includes hack modules like AutoLogin and Account Switcher, making it ideal for players who frequently switch accounts on multiplayer servers.

Download Altmanager

ViafabricPlus

ViaFabricPlus is a Fabric-based mod that enables cross-version compatibility, allowing players to join older Minecraft servers with modern features. It includes select utility modules for enhanced gameplay across different server versions.

Download ViafabricPlus

Doomsday

Doomsday is a powerful hack client tailored for anarchy servers, featuring advanced PvP and griefing modules like Nuker, CrystalAura, and AutoTotem for dominating chaotic environments.

Download Doomsday

ThunderHack Recode

ThunderHack Recode is a modernized version of ThunderHack, offering advanced PvP modules, a sleek GUI, and utility features like AutoCrystal and Baritone integration for enhanced gameplay.

Download ThunderHack Recode

Wurst

Wurst is one of the oldest and most popular open-source hack clients, featuring a vast array of modules like ESP, Nuker, and AutoBuild for diverse gameplay needs on anarchy and SMP servers.

Download Wurst

RavenBs

RavenBs prides itself on being free, supplying enhancing mods to boost your PvP skills against sweats. It’s a Forge-based client optimized for Minecraft 1.8.9, featuring modules like KillAura and Velocity.

Download RavenBs

Fate Injector

Fate Injector is a specialized client for injecting custom hacks and mods, offering a lightweight solution for advanced users and developers looking to customize their Minecraft experience.

Download Fate Injector

Augustus

Augustus is a feature-rich Minecraft client offering a range of PvP and utility modules for players looking to gain an edge on anarchy and survival servers.

Download Augustus

Slinky

Slinky is a lightweight Minecraft client built for players who want a simple, no-frills set of modules for enhanced gameplay.

Download Slinky

VapeV4

VapeV4 is the latest version of the Vape client, packed with polished PvP and utility modules for competitive Minecraft play.

Download VapeV4

Vibe Client

Vibe Client is a versatile Minecraft client offering a smooth GUI and a solid set of modules for PvP and general gameplay enhancement.
